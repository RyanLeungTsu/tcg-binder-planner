
# TCG Binder Planner

A web application for organizing and managing trading card game binders.

## Features

- Create and customize binders
- Organize cards into customizable page layouts
- Track owned and unowned cards
- Browse cards from Pokémon, Yu-Gi-Oh!, and Magic: The Gathering and more to come!
- Customize binder covers

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Status

Currently in development.
